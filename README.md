# synetairismos-astynomikon.gr

Phase 1 rebuild of the homepage on top of Next.js App Router, Tailwind CSS, and shadcn/ui.

## Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- shadcn/ui
- pnpm

## Commands

```bash
pnpm install
pnpm dev
pnpm run check
```

## Phase 1 scope

- Replace the legacy static homepage with a new mobile-first landing page
- Introduce shared design tokens and shadcn-based UI primitives
- Add CI-compatible lint/build checks for the new app setup
